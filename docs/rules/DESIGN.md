# Design

- Read `docs/design/` before styling. No reference files currently exist; use the fallback below until they do.
- Use an editorial, high-contrast, minimal visual language. Avoid generic gradient SaaS cards.
- Give repeat blockers one unmistakable accent treatment; they must be visible in two seconds.
- Prefer typography and spacing over shadows and dense card grids.
- Render all pages and reusable person fragments on the server. Use HTMX for server refreshes and Alpine only for small local state.
- No manual-entry UI in MVP.
